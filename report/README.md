# NSSC 2026 Final Report

This directory contains the final report for the NSSC 2026 problem:

**Unsupervised Anomaly Detection in Mars HiRISE Orbital Imagery**

The final PDF report will document:

- Problem understanding
- Dataset and preprocessing
- Phase 1 — Deep Latent Compression
- Phase 2 — Isolation Forest anomaly detection
- Phase 3 — Reconstruction interpretability
- Phase 4 — Architecture iteration and design journal
- V1 → V2 → V3 engineering iterations
- Statistical anomaly threshold
- Top-5 anomalous samples
- Reconstruction-error heatmaps
- Metadata/location analysis
- Final results and observations
- Limitations and future improvements
